# 规约H：字体大小规约

> 适配 Milkdown 编辑器 | 试卷 / 公文排版场景 | 块级 + 行内双轨体系 核心特征：**块容器与行内标记统一使用显式字体名称**，class 仅作为容器标识，不做字体别名映射；属性统一采用 `key=value` 空格分隔格式，语法风格一致，解析逻辑可复用。

------

## 1. 概述

### 1.1 目的

在标准 CommonMark 基础上扩展排版能力，对齐 Word「段落样式 + 字符样式」排版模型，支持字体、字号、对齐等排版属性，兼顾源码可读性与编辑器交互友好性，适用于中小学试卷、公文等正式排版场景。

### 1.2 底层基础

- 块级容器：基于 `remark-directive` 标准容器指令语法，原生支持嵌套、属性解析
- 行内标记：自定义内联扩展，与块级共用属性解析逻辑
- 渲染目标：Milkdown（ProseMirror）文档模型，可双向序列化 Markdown ↔ 文档树

### 1.3 设计原则

1. **显式优先**：字体名称直接书写，不做隐式别名映射，避免歧义
2. **属性统一**：块级、行内使用相同的属性名（`family`/`size`/`align`），降低记忆成本
3. **边界清晰**：块级作用于整块内容，行内作用于段落内局部文本，分工明确
4. **兼容原生**：不破坏标准 Markdown 语法，扩展标记可降级为普通文本显示

------

## 2. 块级容器指令（`:::`）

用于设置**一个或多个连续段落、列表、块元素**的整体样式，对应 Word「段落样式」。

### 2.1 语法定义

```
::: font{family=字体名 size=字号 align=对齐方式}
内容区域（支持多个段落、列表、嵌套块、行内标记）
:::
```

- 起始标记：单独一行，`:::` + 空格 + `{属性列表}`
- 结束标记：单独一行，与起始标记冒号数量一致的 `:::`
- 属性列表：标准 `attr-list` 语法，**多个属性之间用空格分隔**

### 2.2 属性说明

表格

| 属性名   | 说明                           | 示例                                          | 约束                               |
| -------- | ------------------------------ | --------------------------------------------- | ---------------------------------- |
|          |                                |                                               |                                    |
| `family` | 字体名称，直接写系统字体英文名 | `family=SimSun`、`family="Microsoft YaHei"`   | 字体名含空格时必须用英文双引号包裹 |
| `size`   | 字号，单位为 `pt`（磅）        | `size=12pt`、`size=14pt`                      | 必须带单位，支持小数               |
| `align`  | 段落对齐方式                   | `align=justify`、`align=center`、`align=left` | 可选，默认继承父级                 |

> 扩展预留：后续可追加 `line-height`、`letter-spacing`、`color` 等属性，语法保持一致。

### 2.3 作用范围

- ✅ 支持跨多个自然段（空行分段不中断容器）
- ✅ 支持包含列表、引用、代码块等标准块元素
- ✅ 支持嵌套其他块容器
- ❌ 不能只包裹段落的一部分文字（必须作用于完整块）
- ❌ 不能插在段落中间（起始 / 结束标记必须单独占一行）



### 2.5 渲染模型

解析为 ProseMirror 自定义块容器节点，HTML 输出：

```
<div class="font-block" style="font-family: SimSun; font-size: 14pt; text-align: justify;">
  <p>内容段落</p>
</div>
```



## 4. 行内文本样式标记（`{= :}`）

用于设置**同一段落内局部文字**的样式，对应 Word「字符样式」，优先级高于块级样式。

### 4.1 语法定义

```
{= family=字体名 size=字号 align=对齐方式 : 目标文本内容}
```

- 起始定界符：`{=`
- 属性区：与块级完全一致的 `key=value` 格式，**空格分隔多个属性**
- 分隔符：英文冒号 `:`，用于区分「属性区」与「文本区」，建议前后加空格提升可读性
- 文本区：需要设置样式的行内文字，支持嵌套加粗、斜体等标准行内标记
- 结束定界符：`}`

### 4.2 属性说明

与块级容器属性名、规则完全一致，可复用同一套解析逻辑：

- `family`：字体名，带空格需加引号
- `size`：字号，带 `pt` 单位
- `align`：对齐方式（注：行内元素仅做标记透传，最终对齐由外层块 / 段落生效）

### 4.3 转义规则

如需原样输出 `{=` 字符组合，使用反斜杠转义：

```
\{= family=SimSun : 原样输出，不解析为样式}
```

### 4.4 渲染模型

解析为 ProseMirror 内联 mark（与 `strong`/`em` 同级），HTML 输出：

```
<span style="font-family: SimSun; font-size: 12pt;">目标文本内容</span>
```

------

## 5. 样式优先级与继承规则

### 5.1 优先级顺序（从高到低）

1. **行内标记 `{= :}`**：局部最高优先级，覆盖所有块级样式
2. **内层嵌套块容器**：内层样式覆盖外层容器样式
3. **单段落属性**：覆盖外层容器样式
4. **外层块容器**：作用于容器内所有内容
5. **全局默认样式**：编辑器基础样式

### 5.2 继承规则

- 子元素默认继承父容器的所有样式属性
- 子元素单独设置某属性时，仅覆盖该属性，其余属性继续继承父级
- 示例：外层容器设置宋体 14pt，内层块仅设置楷体，则字号继承外层 14pt

------

## 6. 边界约束与禁忌

### 6.1 块级容器约束

1. ✅ 起始、结束标记必须**单独占一行**，禁止与文本同行
2. ✅ 容器内部可以有空行（分段），空行不会终止容器
3. ❌ 禁止截断段落：不能在一个段落中间插入容器起始 / 结束标记
4. ❌ 禁止跨不连续块：容器必须包裹连续的块元素
5. ❌ 禁止结束标记冒号数量与起始标记不匹配
6. ❌ 属性之间禁止使用逗号分隔，必须使用空格

### 6.2 行内标记约束

1. ✅ 只能存在于**同一个自然段内部**，禁止跨段落
2. ✅ 可以嵌套在块容器、单段落内部使用
3. ❌ 禁止内部包含块元素（段落、列表、标题等）
4. ❌ 禁止跨块容器边界
5. ❌ 属性之间禁止使用逗号分隔
6. ❌ 字体名称前禁止加英文句号（`.SimSun` 为非法写法）

### 6.3 通用约束

1. 字体名称严格区分大小写，建议与系统字体英文名保持一致
2. 带空格的字体名称必须使用英文双引号包裹
3. 字号必须带 `pt` 单位，禁止纯数字
4. 所有属性键名统一为小写：`family`/`size`/`align`

## 7. 完整示例集

### 7.1 基础块级示例

```
::: { family=SimSun size=14pt align=justify}
这是第一段宋体文字，两端对齐。

这是第二段宋体文字，同样继承容器样式。

- 列表项也为宋体14pt
- 第二项同样生效
:::
```

### 

### 7.4 行内样式示例

```
普通正文文字，{= family=KaiTi size=12pt : 这里局部文字为楷体12pt}，后面恢复默认样式。

带空格字体示例：{= family="Microsoft YaHei" size=12pt : 微软雅黑局部文字}。
```

### 7.5 综合试卷场景示例

```
# 第一部分 选择题

::: {family=SimSun size=12pt align=justify}
本大题共10小题，每小题3分，共30分。在每小题给出的四个选项中，只有一项是符合题目要求的。

1. 下列关于xxx的说法，正确的是：
   - A. 选项一
   - B. 选项二
   - C. 选项三
   - D. 选项四



2. 第二题题干……
:::

普通说明段落，{= family=SimSun size=10pt : 小字注释内容}。
```

## 8. 编辑器交互参考规范（Milkdown UI）

1. 块样式按钮
   - 选中完整段落 / 多个块时可用，选中局部文字时置灰
   - 移除样式时仅删除当前层级容器，不影响内部内容
2. 行内样式按钮
   - 选中同段落内局部文字时可用，跨段落选中时置灰
   - 应用后生成 `{= :}` 行内标记包裹选中文本
3. 可视化提示
   - 块容器渲染时添加极淡背景色，直观区分样式范围
   - 鼠标悬浮显示当前样式详情（字体、字号）
