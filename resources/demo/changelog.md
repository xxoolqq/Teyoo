# Teyoo Changelog

欢迎来到 Teyoo 的**可玩 changelog**。左侧面板列出的就是本目录的文件，点击切换，每个文件演示一组功能。这是演示副本，玩坏了随时可以从仓库恢复。

---

## v7.9.0 · 新版本线的第一版

- **这是一个新的开始**：7.9.0 是 Teyoo 这条版本线的第一版。程序标识、安装目录和更新源都换成了新的；如果你装过更早的产品线，请先卸载旧版再装这一版，两者不会互相覆盖
- **应用内更新从这里开始生效**：装上 7.9.0 之后，之后的新版本会在启动后自动检查，界面里给出提示，点一下就能下载，退出应用时静默安装并自动重新打开，不用再回来手动下载安装包
- **两种安装方式**：安装版（`Teyoo-Setup-<版本>.exe`）支持自动更新与文件关联；免安装版（解压即用的 zip）不写注册表、不接管文件关联，也不参与自动更新
- **这一版只发布 Windows 安装包**
