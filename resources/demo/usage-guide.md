# Teyoo 用法指南

由于标准markdown语法表达能力不足，本编辑器对语法进行了扩展，详见Markdown语法指南。

## 功能速览与配置

PDF文档、word文档、图片可转为markdown文本，并可上传到题库。也可从题库中下载markdown格式的习题，打开后打印或是导出为word文档、PDF文档等。

1、PDF文档转md：需要用户到https://mineru.net/注册，并在帮助—偏好设置—图片/PDF转md下，把获取的Token填入。

​      PDF每次最大处理15页，用户可通过帮助—工具箱对PDF进行切分。

2、图片转md，需要的设置同上

3、docx转md。注意只能是docx格式，不支持doc格式。用户需要在word中另存为docx，然后使用此转换功能。docx转md是本地转换。不需要额外配置。

4、文档助手：该功能需要用户注册一个大语言模型API，兼容OpenAI格式。比如deepseek。

5、LaTex公式使用内置大语言模型。

6、新建类docx文档，是实验性功能。不建议使用。
